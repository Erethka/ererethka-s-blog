2026.10.18IDENTITY / 站点整理

博客现在叫 Erelog

博客更名为 Erelog。新的标记把实心 E 字母和折页结合起来，用在导航、首页资料卡与浏览器图标上。深灰与黄绿色的搭配保持不变，小尺寸图标也更清晰。

清理了旧头像、背景配置和不再使用的页面样式，基础布局重新实现。笔记、相册、开箱记录与滚动效果继续保留，图片和第三方工具的来源统一放在「素材与许可」页面。

2026.10.17DESIGN & COPY / 页面细节

封面和相册换成了 SWAV、GUWEIZ 与 loundraw 的城市题材插画，保留清晰原图，并附上作者和来源。

2026.10.17EXPLORE & MOTION / 探索与动画

探索页和滚动动画更新

新增独立的探索页，可以从这里进入技术笔记、插画收藏、Apex 开箱记录和更新日志，也能直接打开相册。

标题、图片和细线会跟随滚动展开，向上滚动时收回。首页增加了图片与文字的错层移动，以及页面切换过渡。系统开启「减少动态效果」时，这些动画会关闭。

2026.10.16CONTENT & TOOLS / 内容与工具

增加笔记检索与阅读工具

首页可以查看最近的笔记。登录后支持搜索标题、分类和标签，也可以按月份筛选、调整排序。

阅读页和编辑预览共用 Markdown 渲染器，补齐表格、图片、嵌套列表、任务列表与文档间链接。阅读时可以定位目录、复制代码、查看进度，或者导出原文、打印为 PDF。

  • 相册可以直接进入对应图片，支持复制链接与打开原图。
  • Apex 记录增加 JSON 备份与重新同步，避免延迟请求覆盖刚录入的内容。
  • 登录窗口支持关闭与重新进入，导航补上退出入口。
  • 音乐播放器支持选择本地音频试听，文件只在当前浏览器播放。

HELP / 使用说明

使用说明

01 / READ

查找笔记

在首页或技术笔记登录，使用标题搜索、分类、标签或月份缩小范围。选择记录后，点「独立阅读」进入专注阅读页。

技术笔记 ↗
02 / WRITE

编辑和导出笔记

支持新建和导入 Markdown。在编辑／分栏中修改后点击保存；更多菜单可以导出当前文稿。阅读页还提供原文导出与打印。

03 / VIEW

浏览相册

按相册名、描述或图片标题搜索，点击画面进入灯箱。左右方向键切换，ESC 返回；图片链接可在刷新后继续定位。

04 / KEEP

记录 Apex 开箱

Apex 页面按开启数量统计 500 包循环。若同步失败，可以重新同步；导出备份会下载当前记录的 JSON 文件。真实记录需要登录后访问。
