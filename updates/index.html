2026.10.17EXPLORE & MOTION / 内容地图与动效

内容地图与滚动动效上线。

“探索”现在拥有独立页面，按技术、影像、Apex 与站点动态组织四个章节。目录提供章节跳转，影像区可以直接打开对应相册。

滚动时，标题、图像遮罩、细线和章节编号一起变化。首页也加入图片与大字的错层位移，并为支持的浏览器补上页面切换过渡。手机端减小位移幅度；启用系统的“减少动态效果”后，页面保持静态阅读。

2026.10.16CONTENT & TOOLS / 内容与工具

让记录能被找到，也能被好好阅读。

首页增加最近技术记录，登录后可以直接搜索文章标题、分类与标签。技术档案补上标签索引、月份归档、分类计数和排序，让积累的笔记有清楚的入口。

阅读页和编辑预览共用 Markdown 渲染器，补齐表格、图片、嵌套列表、任务列表与文档间链接。阅读时可以定位目录、复制代码、查看进度，或者导出原文、打印为 PDF。

  • 影像选集可以直接进入对应图片，支持复制链接与打开原图。
  • Apex 记录增加 JSON 备份与重新同步，避免延迟请求覆盖刚录入的内容。
  • 登录窗口支持关闭与重新进入，导航补上退出入口。
  • 音乐角落支持选择本地音频试听，文件只在当前浏览器播放。

2026.10.16DESIGN / 全站改版

把个人博客整理成一份持续生长的档案。

首页、技术记录、独立阅读页、照片墙与 Apex 页面统一采用受《明日方舟》平面设计启发的档案版式：编号、细线、直角组件，以及克制的黄绿点缀。

深色界面用于长时间浏览，纸色界面提供另一种阅读选择；手机与桌面共用同一套信息层级。原有相册、私人文档接口与开箱记录继续保留。

FIELD GUIDE / 使用说明

从这里开始翻阅。

01 / READ

找一篇技术记录

在首页或技术档案登录，使用标题搜索、分类、标签或月份缩小范围。选择记录后，点「独立阅读」进入专注阅读页。

技术档案 ↗
02 / WRITE

记录与带走笔记

支持新建和导入 Markdown。在编辑／分栏中修改后点击保存；更多菜单可以导出当前文稿。阅读页还提供原文导出与打印。

03 / VIEW

按相册翻阅画面

按相册名、描述或图片标题搜索，点击画面进入灯箱。左右方向键切换，ESC 返回；图片链接可在刷新后继续定位。

04 / KEEP

管理私人游戏记录

Apex 页面按开启数量统计 500 包循环。若同步失败，可以重新同步；导出备份会下载当前记录的 JSON 文件。真实记录需要登录后访问。
