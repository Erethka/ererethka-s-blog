# ererethka の 宝藏之地

静态个人博客，包含技术档案、影像相册和 Apex 补给记录。全站采用受《明日方舟》平面设计启发的档案版式：深灰／纸色双主题、黄绿点缀、编号、细线分区与直角组件。保留原有个人图片与内容，没有使用游戏角色或官方标识作为界面素材。

## 页面

- `/`：个人首页、最近技术记录、站内搜索、影像选集、站点更新与本地音频试听。文章索引仅在登录后读取，加入搜索结果；音频使用浏览器本地文件，不上传。
- `/explore/`：独立的内容地图，包含技术、影像、Apex 与动态四个章节。目录和章节轨道支持直接跳转，不再用首页锚点作为“探索”导航。
- `/dev/`：搜索、分类计数、标签索引、月份归档与排序；支持 Markdown 导入、导出，以及阅读、编辑和分栏视图。
- `/dev/reader.html?doc=…`：独立阅读页，包含目录定位、标签、上一篇／下一篇、阅读进度、字数／预计时长、代码复制、原文导出和打印／PDF 样式。
- `/photowall/`：相册检索、图片灯箱与原图入口。`?album=相册名&photo=序号` 可以定位到相册图片，并支持复制链接和键盘操作。
- `/apex/`：累计数量、500 包循环进度与历史记录，支持重新同步和 JSON 备份导出。同步请求串行执行，期间新增的记录会继续同步。
- `/404.html`：失效链接的返回入口；`/sitemap.xml` 仅列出公开页面。
- `/updates/`：公开的站点更新日志与使用指南；`/feed.xml` 只订阅这些公开更新，不包含私人文章标题或正文。

全站公共颜色和导航样式在 `site-polish.css`，首页样式在 `styles-polish.css`；各子页样式位于对应目录。首页保留 `#home`、`#projects`、`#timeline`、`#photowall`、`#music` 与 `#about` 锚点。

`motion.css` 与 `motion.js` 管理分区遮罩入场、细线展开、滚动图形位移、章节定位和滚动进度。滚动沿用浏览器原生行为；滚动帧通过 `requestAnimationFrame` 合并，并先读取布局再更新样式。`navigation-motion.js` 在 head 中注册原生跨文档过渡事件，兼容快速切换和取消导航。支持 View Transitions 的浏览器提供页面切换过渡，其他浏览器正常导航。

启用系统“减少动态效果”时关闭入场与图形位移；禁用 JavaScript 时仍完整显示页面内容。技术编辑器正文与输入区不参加滚动位移动画。

## 私人数据

技术文档和 Apex 记录继续通过现有 Cloudflare Worker 代理访问 GitHub 私有仓库。访问私人页面时使用口令登录；浏览器通过会话 Cookie 请求接口，不需要填写或保存 GitHub Token。Worker 部署说明见 `worker/README.md`。

首页登录为可选操作，私人页面会提示登录。公共导航提供登录与退出入口，手机端入口在展开的菜单中。退出会清除 Apex 本机缓存并刷新页面；编辑器有未保存修改、Apex 有未同步记录时会先保护当前工作。登录弹窗可按 ESC 关闭，登录失败或浏览器阻止会话 Cookie 时显示原因。

预览与独立阅读共用本地固定版本的 markdown-it 渲染器，支持表格、图片、嵌套列表、任务列表、引用与文档间链接。原始 HTML 解析关闭；私人文档页不加入公开站点地图，也不提供公开文章订阅。

Apex 的显示进度按累计包数对 500 取余计算，不根据是否获得传家宝重置。浏览器保留本地记录缓存，新增与删除操作继续使用原有私人同步接口。界面中的循环数字仅是个人记录统计。

## 本地预览

在项目根目录启动静态 HTTP 服务器，例如：

```sh
python -m http.server 4173
```

访问 `http://localhost:4173/`。私人接口沿用生产环境的 Origin 和会话配置；本地验收使用独立的模拟响应，不修改真实私人记录。

项目没有前端构建步骤。发布沿用仓库现有 GitHub Pages 配置；修改 CSS 或 JavaScript 后，应同步更新 HTML 中的资源版本参数，避免浏览器使用旧缓存。
