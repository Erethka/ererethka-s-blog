# Erelog

静态个人博客，包含开发笔记、插画相册与 Apex 开箱记录。页面使用深灰／纸色双主题、黄绿色点缀、编号与细线，平面设计参考《明日方舟》的信息编排风格。

## 页面与功能

- `/`：个人简介、站内搜索、最近笔记、插画选集、更新日志与本地音乐播放。私人笔记仅在登录后读取，本地音频不上传。
- `/explore/`：独立栏目导览，包含笔记、插画、开箱记录和站点动态，支持章节跳转。
- `/dev/`：笔记搜索、分类、标签、月份筛选与排序；Markdown 新建、导入、编辑、分栏预览与导出。
- `/dev/reader.html?doc=…`：文章目录、阅读进度、标签、代码复制、上一篇／下一篇，以及原文导出和打印。
- `/photowall/`：相册搜索、图片灯箱、原图与作者来源。支持 `?album=相册名&photo=序号` 定位、分享和键盘操作。
- `/apex/`：累计开箱数量、500 包循环进度、历史记录、重新同步与 JSON 备份。
- `/updates/`、`/feed.xml`：公开的站点更新与 RSS，不包含私人文章或游戏数据。
- `/credits.html`：本站标识、插画与第三方工具的来源说明。
- `/404.html`、`/sitemap.xml`：失效链接返回入口与公开页面索引。

## 样式与标识

`base.css` 提供基础布局与浏览器默认样式整理；`site-polish.css` 管理共享配色、导航、登录窗与控件。首页版式在 `styles-polish.css`，子页面的版式位于各自目录。

`assets/identity/erelog-mark.svg` 为本站绘制的折页字母标记，用于导航和首页资料卡；浏览器图标提供 `assets/favicon.svg` 与多尺寸 `assets/favicon.ico`，并包含 180 像素主屏幕图标及 512 像素 PNG 标记。当前版本不依赖旧头像、旧背景配置或旧的整页参考样式层。

`motion.css` 和 `motion.js` 以滚动位置控制遮罩、细线、图形位移、章节定位和滚动进度；下滚展开，上滚收回。`navigation-motion.js` 处理页面过渡与主动主题切换。减少动态效果模式会关闭动画，禁用 JavaScript 时正文仍可阅读。

首页保留 `#home`、`#projects`、`#recent`、`#photowall`、`#timeline`、`#music` 与 `#about` 锚点。

## 私人内容

笔记与开箱记录使用现有 Cloudflare Worker 登录与同步接口，通过会话 Cookie 请求 GitHub 私有仓库；浏览器不保存 GitHub Token。部署说明见 `worker/README.md`。

首页登录可选，私人页面会提示登录。编辑器保护未保存的修改，开箱记录保护尚未同步的数据。Markdown 使用本地固定版本的 markdown-it，关闭原始 HTML 解析。私人页面不加入公开站点地图。

开箱进度按累计数量对 500 取余计算，不根据实际掉落重置，仅供个人记账参考。

## 本地预览与发布

在仓库根目录启动静态服务器：

```sh
python -m http.server 4173
```

访问 `http://localhost:4173/`。本地功能验收使用模拟响应，不修改真实私人记录。

项目没有构建步骤，沿用 GitHub Pages 发布。更改资源后同步更新 HTML 的版本参数。浏览器截图和验收脚本放在已忽略的 `output/playwright/` 中。
